# Shelf
A tiny app store for you and your friends. No login. Apps, games and websites with screenshots, ratings and reviews.

1. Supabase: SQL Editor > New query > paste supabase.sql > Run.
2. Open config.js, paste your Supabase URL and anon/publishable key.
3. Upload every file in this folder to a GitHub repo (main branch).
4. Vercel > Add New > Project > pick the repo > Deploy.

Remove a bad listing: Supabase > Table Editor > apps > delete the row.
